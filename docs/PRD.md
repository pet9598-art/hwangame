# 황룡강 수달 헤엄 러너 — Game Design Doc v0.2

> v0.1 원본: [Artifact](https://claude.ai/code/artifact/79e68cb3-d2f3-41f2-9cff-64d23f20b611)
> **v0.2 변경점**: 스테이지별 생물(우호/유해 생물, 도감) 시스템 제거 → 장애물은 쓰레기·소다캔·통나무·바위 등 실제 확보 에셋 기반으로 단순화. 조개 수집 + 공격 시스템 추가. 보스(쓰레기봉투) 등장. 참고 게임 형식 명시.

- **장르**: 3D 오토러너 (레인 스위밍 액션 + 원거리 공격)
- **배포**: GitHub Pages
- **에셋 포맷**: .glb
- **대상**: 초등학생 · 웹/태블릿
- **참고 게임**: [James Street Runner 3D](https://game-dev-office.netlify.app/games/%EB%8B%AC%EB%A0%A4%EB%9D%BC%20%EB%B0%B1%ED%98%84%EC%9A%B0.html) — 3레인 오토러너, 좌우/점프/슬라이딩 조작, 상단 UI(좌: 점수 / 중앙: 속도 게이지 / 우: 이동거리), 레인 위 코인·장애물 배치 구조를 그대로 참고

입암산 발원지에서 영산강까지, 강폭이 점점 넓어지는 물길을 따라 자동으로 헤엄쳐 내려가는 3D 오토러너. 좌우 이동·점프·슬라이딩(잠수)으로 장애물을 피하고, 조개를 모아뒀다가 장애물이나 보스를 공격하며 하류까지 도달한다.

## 여정 지도

① 입암산 발원지 (좁은 계곡물) → ② 장성호 → ③ 읍내 구간 → ④ 영산강 합류부 (강폭 최대 · 보스전 · 엔딩)

## 1. 핵심 루프 & 조작

강물이 자동으로 캐릭터를 하류 방향으로 밀어낸다. 참고 게임(James Street Runner)과 동일하게 상단 UI에 **점수(좌) / 속도 게이지(중앙) / 이동거리(우)** 를 배치한다.

| 조작 | 설명 |
|---|---|
| 자동 전진 | 기본 유속으로 항상 전진. 스테이지가 진행될수록 유속이 점차 빨라짐 |
| 좌우 이동 (⇄) | 3레인(좌·중·우) 기준 스와이프 또는 방향키. 교각·통나무 등 옆으로 피하는 장애물용 |
| 점프 (↑) | 짧게 튀어 오름. 낮게 깔린 장애물(쓰레기봉투, 찌그러진 캔 등) 회피 |
| 슬라이딩/잠수 (↓) | 잠깐 물속으로 잠김. 그물·다리 등 머리 위를 가로막는 장애물 통과 |
| **공격 (신규)** | 보유한 조개를 소모해 정면 장애물이나 보스를 파괴/타격 |

충돌 처리(속도 감속 / 코인 손실 / 라이프제 등)는 프로토타입 플레이테스트 후 확정 권장. 기본안: **라이프 3개 + 피격 후 짧은 무적시간(i-frame)**.

## 2. 조개 · 공격 시스템 (신규)

- 수달(플레이어)은 레인 위에 떠 있는 **조개**를 먹으면(코인처럼 수집) 보유 개수가 쌓인다.
- 보유한 조개 개수만큼 **공격**을 사용할 수 있다 (공격 1회 = 조개 1개 소모, 소모량은 밸런스 조정 대상).
- 공격은 정면의 파괴 가능한 장애물(예: 쓰레기봉투, 찌그러진 캔)을 없애거나, 보스에게 데미지를 준다.
- 조개가 없으면 공격 불가 → 회피(좌우/점프/잠수)로만 대응해야 함. 이 자원 관리가 핵심 전략 요소.

## 3. 보스 시스템 (신규)

- 보스는 **쓰레기봉투**(에셋: `boss/boss.glb`)이며, 러닝 필드로 쓰레기 투사체(에셋: `boss/trash for attack-....glb`)를 소환해 플레이어 레인으로 날려보낸다.
- 플레이어는 투사체를 회피(좌우/점프/잠수)하거나, 조개를 소모해 반격/파괴할 수 있다.
- 보스 등장 시점은 **영산강 합류부(스테이지 4) 후반**으로 잠정 배치 (스테이지 전환마다 미니보스로 넣을지는 추후 확정 필요).
- 보스 처치 시 스테이지 4 엔딩으로 연결.

## 4. 스테이지 구성 원칙

실제 황룡강의 흐름(입암산 → 장성호 → 장성읍내 → 영산강 합류)을 그대로 지도로 삼는다. 강이 하류로 갈수록 실제로도 폭이 넓어지므로, 레벨 난이도 곡선과 연결한다.

| 스테이지 | 강폭 연출 | 유속/난이도 | 레인 수 | 분위기 |
|---|---|---|---|---|
| ① 입암산 발원지 | 좁은 계곡 개울 | 느림 (튜토리얼) | 2레인 | 맑은 물, 이끼바위, 그늘 |
| ② 장성호 | 넓은 저수지 | 보통 | 3레인 | 잔잔한 호수, 인공 구조물 등장 |
| ③ 읍내 구간 | 도심 하천 | 빠름 | 3레인 | 다리·둔치, 생활 오염 흔적 |
| ④ 영산강 합류부 | 가장 넓은 강 | 가장 빠름 | 3~4레인 | 큰 배, 노을, 보스전, 엔딩 |

## 5. 스테이지별 상세 PRD

생물 등장 없이, **장애물 회피 + 조개 수집/공격**을 중심으로 구성한다. 교각·그물·집(마을) 에셋은 추가로 확보 예정.

### STAGE 1 — 입암산 발원지 (튜토리얼 · 좁은 계곡)
황룡강의 시작점. 폭이 좁고 물살이 잔잔해 조작을 익히기 좋다.

- **장애물**: [좌우] 바위(`enemy/Rock...glb`) / [점프] 낮은 통나무(`enemy/log.glb`) / [잠수] 낮게 걸린 나뭇가지 (추가 확보 예정)
- **수집**: 조개(공격 자원)
- **필요 glb**: 수달(플레이어, 확보), 바위(확보), 통나무(확보), 계곡 배경(추가 확보 예정)

### STAGE 2 — 장성호 (저수지 · 인공 구조물 등장)
계곡물이 모여 만든 넓은 저수지. 낚시·오리배 같은 인공 구조물이 처음 등장한다.

- **장애물**: [좌우] 교각/부표 (추가 확보 예정) / [잠수] 그물 (추가 확보 예정) / [점프] 찌그러진 캔(`enemy/Soda Can Crushed...glb`)
- **수집**: 조개
- **필요 glb**: 저수지 제방 배경(추가 확보 예정), 그물(추가 확보 예정), 오리배/부표(추가 확보 예정)

### STAGE 3 — 읍내 구간 (도심 하천 · 오염 밀도 상승)
장성 읍내를 가로지르는 구간. 다리 교각과 둔치 공원이 이어지고, 생활 쓰레기가 눈에 띄게 늘어난다.

- **장애물**: [좌우] 다리 교각 기둥 (추가 확보 예정) / [잠수] 낮은 다리 하부 (추가 확보 예정) / [점프/공격 가능] 쓰레기봉투·찌그러진 캔·배설물(`enemy/poop...glb`)
- **수집**: 조개
- **필요 glb**: 다리/교각(추가 확보 예정), 둔치 공원(추가 확보 예정), 집/마을 실루엣(추가 확보 예정)

### STAGE 4 — 영산강 합류부 (최대 강폭 · 보스전 · 엔딩)
황룡강이 영산강과 만나는 가장 넓은 구간. 노을 지는 합류 지점에서 보스(쓰레기봉투)와 마주친다.

- **장애물**: [좌우] 화물선/바지선 측면 (추가 확보 예정) / [점프] 대형 부유물 (추가 확보 예정) / [잠수] 소용돌이 구간
- **보스전**: 보스가 쓰레기 투사체를 소환 → 회피 또는 조개로 반격 → 처치 시 클리어
- **엔딩**: 합류 지점 도달 시 자동 클리어, 생태 메시지 카드 노출
- **필요 glb**: 영산강 합류부 배경(추가 확보 예정), 화물선/바지선(추가 확보 예정), 노을 스카이박스(추가 확보 예정), 보스(확보), 보스 투사체(확보)

## 6. 조작 매핑 원칙

일관된 규칙이 있어야 아이들이 빠르게 학습한다.

| 장애물 특징 | 회피 조작 | 예시 |
|---|---|---|
| 바닥/수면 낮게 깔린 것 | 점프 | 찌그러진 캔, 쓰레기봉투, 대형 부유물 |
| 머리 위를 가로막는 것 | 잠수(슬라이딩) | 그물, 다리 하부, 낮은 나뭇가지 |
| 레인 한쪽을 막는 것 | 좌우 이동 | 교각 기둥, 바위, 배 측면 |
| 파괴 가능한 것(보스 포함) | 공격(조개 소모) | 쓰레기봉투, 보스 투사체 |

## 7. 점수 · 수집 시스템

- **거리 점수** — 이동 거리에 비례해 자동 누적
- **조개** — 레인 위에서 수집, 공격 자원으로 소모되는 동시에 보유량 자체가 점수에도 반영
- **감점/페널티** — 장애물 충돌 또는 오염 구간(녹조 등) 통과 시 점수 또는 라이프 차감
- ~~생물 도감~~ (v0.1 제거됨 — 생물 시스템 삭제로 도감 불필요)

## 8. 환경 교육 포인트 (제안)

생물 시스템은 뺐지만, **하천 오염** 메시지는 장애물 자체(쓰레기봉투·찌그러진 캔·배설물)로 계속 전달할 수 있다.

- 스테이지 전환 시 짧은 정보 배너: "여기는 입암산, 황룡강이 시작되는 곳이에요" 같은 실제 지리 정보
- 수달이 멸종위기종(법정보호종)이라는 사실을 로딩/엔딩 화면에 자연스럽게 노출
- "사람이 버린 쓰레기가 강 하류로 흘러가며 쌓인다"는 것을 스테이지가 진행될수록 오염 밀도가 늘어나는 연출로 체감시킴
- 엔딩에서 "이번 여정에서 치운 쓰레기 개수" 요약 — 성적표가 아니라 관찰/정화 기록처럼

※ 지리 정보는 기존 프로젝트 조사 결과를 재사용. 학생 배포 전 장성군 환경 자료 등으로 최신 사실 확인 권장.

## 9. 강물 표현 방안 (확정)

외부 물 셰이더 에셋을 구하지 않고 **직접 구현**하기로 확정.

- 정점 셰이더로 간단한 사인파 물결 + Fresnel 기반 가장자리 밝기 + 깊이에 따른 색 그라데이션을 사용한 스타일라이즈드 물 (Three.js `ShaderMaterial`)
- 외부 텍스처/노멀맵 없이 코드만으로 구현 — Kenney류 저폴리 에셋과 톤이 잘 맞음
- 개발 재개 시 이 방식으로 바로 구현

## 10. 기술 스택 & 배포

- **렌더링** — Three.js + GLTFLoader
- **에셋 파이프라인** — .glb 모델을 저장소에 직접 커밋 → GitHub Pages 정적 배포 (`3d-rpg-demo` 저장소와 동일 방식)
- **조작 입력** — 키보드(방향키/스페이스/공격키) + 터치(좌우 스와이프, 탭=점프, 아래로 스와이프=잠수, 별도 버튼=공격) 동시 지원
- **레포 구조 제안** — `/models`(glb), `/textures`, `/src`(게임 로직), `index.html`

## 11. 확보가 필요한 에셋 체크리스트

자세한 보유 현황은 [docs/ASSETS.md](ASSETS.md) 참고. 사용자가 직접 찾아줄 항목: **교각, 그물, 집(마을 실루엣)**. 그 외 스테이지 배경, 노을 스카이박스 등은 추가 확보 필요.
